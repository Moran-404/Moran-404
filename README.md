# PyQt5 在线音乐播放器

一个简洁的 PyQt5 桌面音乐播放器，支持：

- 在线音频 URL 播放（HTTP/HTTPS）
- 本地音频文件导入
- 播放列表管理（添加、双击播放、删除）
- 播放/暂停/停止控制
- 播放进度条拖动

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用说明

1. 在 URL 输入框中粘贴可访问的音频链接（例如 `.mp3` 直链）。
2. 歌曲名称可选，不填会自动使用链接文件名。
3. 点击“添加到播放列表”，再选择歌曲并点击“播放”。
4. 也可点击“导入本地文件”添加本地音频。

## 注意

- 在线播放依赖音频链接可直接访问，且格式受系统解码器支持情况影响。
- Linux 环境下若无法播放，可能需要额外安装系统多媒体后端（如 GStreamer 插件）。
