# Moran 多平台 PyQt5 音乐播放器

现代风格的桌面音乐播放器，支持聚合搜索与在线播放，覆盖平台：

- 网易云音乐
- 酷狗音乐
- 酷我音乐
- Bilibili

## 功能特性

- 多平台聚合搜索（直接调用各平台公开搜索接口，非 YouTube 搜索兜底）
- 双击或按钮加入播放列表
- 使用 `yt-dlp` 解析可播放音频流并在线播放
- 应用内登录视图（优先内置网页标签，缺失 WebEngine 时自动降级）
- 导出或导入平台 Cookies 供受限资源解析使用
- 播放选中 + 暂停/播放一键切换与进度拖动
- 深色现代 UI 样式

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用说明

1. 输入关键词并勾选要搜索的平台，点击“聚合搜索”。
2. 在结果中选择条目，点击“加入播放列表”或直接双击。
3. 在播放列表中选择歌曲点击“播放选中”或双击播放。
4. 如遇到受限资源，点击“平台登录”，在内置页面完成登录后导出当前平台 Cookies。
5. 再次播放时程序会自动把对应平台 Cookie 用于解析。

## 注意事项

- 解析能力取决于 `yt-dlp` 对目标站点支持情况以及资源是否可访问。
- 部分平台可能因地区、版权或账户等级限制导致无法解析。
- Linux 下若无法播放，请检查系统多媒体后端（GStreamer/FFmpeg）。
- 若未安装或无法正常使用 `PyQtWebEngine`，程序仍可运行，可在登录窗口中一键切换到“系统浏览器登录当前平台”并导入 Cookie 文件。

- 若已安装且版本匹配但内嵌登录仍空白，优先在登录弹窗查看 “WebEngine 诊断” 信息，并使用“系统浏览器登录当前平台 + 导入 Cookie 文件”继续使用。
- Windows 下可尝试在启动前设置环境变量 `QTWEBENGINE_CHROMIUM_FLAGS=--disable-gpu` 以规避部分显卡驱动导致的空白页面问题。

## 搜索异常排查

- 当前版本搜索走各平台接口，不会再主动请求 YouTube。
- 若全部平台都返回 0 条，常见原因是网络被目标站点拦截、接口限流或关键字过于冷门。
- 可先只勾选单个平台测试，便于定位具体平台是否可用。
