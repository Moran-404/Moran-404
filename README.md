# PyQt5 在线音乐播放器（聚合搜索版）

一个更偏现代化 UI 的 PyQt5 桌面音乐播放器，支持按**歌曲名直接搜索**，并聚合以下来源：

- 网易云音乐
- 酷狗音乐
- 酷我音乐
- Bilibili

> ⚠️ 说明：不同平台的版权/会员/地区策略不同，部分歌曲可能无法解析或播放。

## 功能亮点

- 深色主题 UI（更美观、布局更清晰）
- 按关键词搜索歌曲（歌名/歌手）
- 多平台勾选聚合搜索
- 搜索结果一键加入播放列表
- 双击播放、播放/暂停/停止、进度条拖动
- 内置平台登录窗口（WebEngine），可在应用内打开各平台官网进行登录

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用说明

1. 输入关键词（例如：稻香）。
2. 勾选要搜索的平台后点击“搜索”。
3. 在左侧搜索结果中选中歌曲，点击“加入播放列表”。
4. 双击右侧播放列表歌曲，或点“播放”。
5. 如果某些资源受限，可点“平台登录”进入对应网站登录页。

## 技术实现简述

- 搜索：通过各平台公开/常见搜索接口拉取结果。
- 播放：借助 `yt-dlp` 解析详情页可播放音频流，再交给 `QMediaPlayer` 播放。
- 登录：通过 `QWebEngineView` 内嵌网页登录入口。

## 已知限制

- 平台接口或页面结构变化会影响可用性。
- 部分歌曲需要会员或仅客户端可播。
- Linux 环境可能需要安装系统多媒体后端（如 GStreamer 插件）。
