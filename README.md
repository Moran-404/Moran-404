# Moran 多平台 PyQt5 音乐播放器

现代风格的桌面音乐播放器，支持聚合搜索与在线播放，覆盖平台：

- 网易云音乐
- 酷狗音乐
- 酷我音乐
- Bilibili

## 功能特性

- 多平台聚合搜索（直接调用各平台公开搜索接口，非 YouTube 搜索兜底）
- 结果按平台轮询混排展示，避免单一平台结果“刷屏”
- 双击或按钮加入播放列表
- 使用 `yt-dlp` 解析可播放音频流并在线播放
- 浏览器登录视图（直接打开系统浏览器登录，避免内嵌 WebEngine 崩溃）
- 可选导出/导入 Cookie（高级场景）
- 登录窗口支持“免导入：读取浏览器登录态”，可直接读取浏览器已登录 Cookie（无需手动导出/导入文件）
- 平台登录后会在终端输出登录态检测结果（是否命中平台 Cookie），便于判断会员登录是否真正生效。
- 播放选中 + 暂停/播放一键切换与进度拖动
- 深色现代 UI 样式

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用说明

1. 输入关键词并勾选要搜索的平台，点击“聚合搜索”。
2. 在结果中选择条目，点击“加入播放列表”或直接双击。
3. 在播放列表中选择歌曲点击“播放选中”或双击播放。
4. 如遇到受限资源，点击“平台登录”，选择“打开浏览器登录并启用当前平台”，在浏览器完成登录。
5. 回到播放器直接播放，程序会自动读取浏览器登录态解析（无需手动导入 Cookie）。
6. 搜索完成后，状态栏会显示各平台数量（如 网易云:6 / 酷狗:5）。

## 注意事项

- 推荐先在系统默认浏览器（Windows 通常为 Edge）登录平台账号，再回播放器播放。
- 解析能力取决于 `yt-dlp` 对目标站点支持情况以及资源是否可访问。
- 酷狗/酷我接口会做更严格反爬校验，程序已切换更稳定接口并增加 Kuwo token 请求；若仍偏少，通常是接口限流或地区策略。
- 部分平台可能因地区、版权或账户等级限制导致无法解析。
- 即使已登录会员，部分平台歌曲受 DRM/版权策略限制，第三方解析仍可能只能得到试听流。
- Linux 下若无法播放，请检查系统多媒体后端（GStreamer/FFmpeg）。

- 若不想手动导入 Cookie，可在“平台登录”中选择“免导入：读取浏览器登录态”，并先在对应浏览器完成登录。
- 播放解析过程会在状态栏和终端输出“使用了哪种解析方式（浏览器登录态 / Cookie 文件 / 未登录）”，便于排查为何仍是试听流。
- 终端会输出“正在解析页面 URL”和“最终播放流 URL”，便于定位是否卡在特定资源链接。
- 终端还会输出“播放请求头字段（隐藏 Cookie 值）”，用于判断是否携带了 Referer/User-Agent/Cookie 以绕过防盗链。
- 若播放解析长时间无响应，程序会限制解析重试与超时（默认约 7 秒 socket 超时，并减少浏览器候选数量）以避免长时间卡住。
- 若终端出现“Could not copy Chrome cookie database”，程序会自动尝试 Edge/Firefox；如仍失败，请先完全退出对应浏览器后再点“平台登录”。
- 对会员/受限资源，解析时会优先尝试浏览器登录态与 Cookie，再回退到未登录解析，减少被命中为试听链接的概率。

## PR 冲突处理建议

当 GitHub 提示 **This branch has conflicts** 时，不建议直接“一键接受当前变化”。更安全的做法是：

1. 先查看冲突文件和每段冲突含义（当前分支 vs 目标分支）。
2. 只有在你确认目标分支对应改动不需要保留时，才选择“接受当前变化”。
3. 更推荐逐段手动合并：保留双方都需要的逻辑，再进行运行验证。
4. 解决后至少执行一次基础检查（例如 `python -m py_compile main.py`）再提交。

简化判断：

- **仅文案冲突** 且你明确只要当前分支内容：可以接受当前变化。
- **代码逻辑冲突**（函数、依赖、线程、播放流程等）：不要盲点接受，需人工合并并验证。


## 搜索异常排查

- 当前版本搜索走各平台接口，不会再主动请求 YouTube。
- 若全部平台都返回 0 条，常见原因是网络被目标站点拦截、接口限流或关键字过于冷门。
- 可先只勾选单个平台测试，便于定位具体平台是否可用。
